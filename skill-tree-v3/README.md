# 💪 SKILL TREE

## <mark style="color:yellow;">**What's new in v3**</mark>

* 🎨 **Theme system** — switch between `legacy`, `modern`, `zombie`, and `fantasy` looks via `Config.Theme`
* 🩸 **Skill degradation** — optional per-skill mechanic that requires players to keep earning XP to maintain unlocked effects
* 📅 **Daily XP limits** — cap how much XP a player can earn per category each day
* 💎 **Premium currency** — optional secondary currency for unlocking skills
* 🛡️ **Admin panel** — in-game dashboard for managing player XP, points, and skills (online + offline)
* 💾 **Config backup system** — automatic and manual backups before each generator save (exclusive only)
* 🏃 **6 new XP-earning activities** — `climbing`, `parachuting`, `flying`, `boating`, `reloading`, `takingDamage`
* 🎯 **Trigger events on skill unlock** — fire your own events automatically when a player unlocks a skill
* 🧰 **Server helper library** — drop-in helpers for jobs, items, money, identifiers in your unlock handlers
